## Full-vault sync

- Adds acceptance-gated **managed Google Drive vault sync**: an entire vault can be bound to a shared Drive target and synchronised, rather than syncing documents one at a time. Sync never begins implicitly — a binding must be created or joined, previewed, and explicitly approved. ([#26](https://github.com/rbcodelabs/obsidian-gdocs-sync/pull/26))
- History is append-only and immutable: each change publishes a new record rather than overwriting, so concurrent edits from different devices are preserved as separate versions instead of one silently winning.
- Local absence does not delete remote files. Joining an existing shared vault from an empty local vault will not propagate deletions.
- Scope is explicit. Community plugins and community plugin data are excluded; managed and excluded paths are reported in the preview rather than being synced silently.

## Fixes and improvements

- **Immutable bytes are now verified across Drive version changes.** A blob is checked against its recorded hash and size on read, so a file whose Drive-side version changed underneath an in-flight sync is rejected rather than applied. This is the fix the manual two-client acceptance run was validated against, and the pull request head was fast-forwarded to include it before merge so the released code is the tested code.
- Adds an executable three-profile acceptance driver and redacted auth-phase checkpoints under `tests/live/`, so a manual multi-client run is reproducible rather than ad hoc. These are developer tools; they are not part of the shipped plugin bundle.

## Conflict resolution lives in the host app

- This release makes concurrent edits **surface** as explicit conflicting versions. It does not add conflict-resolution UI to the plugin.
- Reviewing and resolving a conflicted note is a host-application concern. In Geode that surface now exists (an in-note banner and a read-only side-by-side comparison); in Obsidian, conflicts are resolved through the plugin's Sync settings list.

## Update and reconnect

- Update Google Docs Sync through BRAT and reload Obsidian or Geode. This release includes `main.js`, `manifest.json`, and `styles.css`.
- No new Google scopes are requested by this release. An existing connection continues to work; no disconnect/reconnect is required unless you are also picking up the v0.7.1 auth-proxy scope change.
- Requires Obsidian 1.4.0 or later.

## Verification and known limits

- Automated verification on the merged commit: **345 passing tests across 20 files**, clean TypeScript (`tsc --noEmit`), and a successful production build. CI unit tests green on the merged head.
- Manual acceptance was performed with **two independent desktop clients** joining one shared vault and propagating edits between them. That run validated the same blob-integrity fix included here.
- **Not verified:** broad live acceptance beyond that two-client run — corporate Shared Drive tenancy, large-vault performance, and long-running multi-day convergence remain unproven. Automated tests do not replace those checks.
- **Not verified:** the `tests/live/` acceptance driver requires real Google credentials and was not exercised as part of this release's automated gate.
- Treat full-vault sync as an early, explicitly gated capability. Keep independent backups of any vault you bind.
