## Bug Fixes

Fixes narrow-sidebar layout and Geode form-control styling in the Tasks view ([#54](https://github.com/rbcodelabs/obsidian-gdocs-sync/pull/54)):

- **Narrow sidebar layout & overflow:** Fixed the `My Tasks` list dropdown overlapping the quick-add input and spawning a stray horizontal scrollbar in narrow Geode sidebars (`select.dropdown` `min-width` reset and `.view-content.gtasks-view` overflow isolation).
- **Responsive filter & quick-add stacking:** Stacked filter tabs (`Today` / `Upcoming` / `Overdue` / `All`) above `All lists` and stacked quick-add `Add to [List]` above `[Add a task…] [+]` in narrow sidebars (`< 560px`), keeping single-row layouts in wide tabs (`>= 560px`) and eliminating filter tab label clipping down to `260px`.
- **Geode light & dark form controls:** Styled bare text and date `<input>` controls for Geode light and dark themes, including a dark-mode `color-scheme: dark` calendar picker icon, dark select chevron contrast, and `forced-colors`-safe `:focus-visible` outlines.
- **Hover states, fallbacks & truncation:** Guarded task-title and unchecked checkbox hover states against Geode's global `button:hover` background, added Geode CSS variable fallbacks (`--color-cyan`, `--color-pink`, `--text-error`, `--text-warning`, `--font-normal`, `--font-semibold`), and capped wide-row list metadata width so long list names ellipsis cleanly.

## Improvements

- **Focus preservation:** Preserved keyboard focus on row `Edit` and `Open note` buttons across background refreshes.
