## Fixes and improvements

- A token refresh finishing after disconnect, reconnect, or an auth-proxy change can no longer replace or clear the current Google connection. Concurrent refreshes for the same connection share one request. ([#28](https://github.com/rbcodelabs/obsidian-gdocs-sync/pull/28))
- Refresh requests stop waiting after 30 seconds and allow retry; late responses are ignored.
- Exposes connection-guard support required by the opt-in Google Workspace MCP integration in Agent Threads.

## Update and reconnect

- Update Google Docs Sync through BRAT and reload Obsidian or Geode before enabling the Workspace MCP beta. This release includes `main.js`, `manifest.json`, and `styles.css`.
- The companion [auth proxy update](https://github.com/rbcodelabs/obsidian-gdocs-auth/pull/6) requests additional Docs, Sheets, and Slides permissions alongside existing Drive and Tasks permissions. Disconnect and reconnect Google Docs Sync to approve the expanded scopes; refreshing an existing token does not grant them. Self-hosted deployments must update the auth proxy too.
- When changing auth hosts, disconnect before changing **Auth Proxy URL**, then reconnect with the intended account. Workspace MCP additionally requires the relevant APIs and MCP services enabled and Google Developer Preview enrollment.
- Workspace MCP rollout is an opt-in beta. Live corporate-account acceptance—including fresh consent, MCP document access, and desktop sync—remains pending work-machine validation. Automated tests do not replace those checks.
- Requires Obsidian 1.4.0 or later. Automated verification: 247 passing tests, clean TypeScript, and successful production build; existing Shared Drive support is retained.
