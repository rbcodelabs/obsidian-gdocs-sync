## Features

- **Google Workspace Shared Drives** — browse Shared Drives alongside My Drive, select folders for sync, or import using a folder URL. Existing mapped Shared Drive folders now use Drive-aware queries. ([#27](https://github.com/rbcodelabs/obsidian-gdocs-sync/pull/27))

## Fixes and improvements

- Folder imports and browsing follow all result pages, including nested folders and accounts with more than 100 Shared Drives. A failed page reports an error instead of returning a partial import.
- Drive picker navigation now supports the keyboard, preserves parent breadcrumbs, and ignores stale responses after navigating elsewhere or closing the picker.
- Release downloads include `styles.css` alongside `main.js` and `manifest.json`.

## Notes

- No new OAuth scopes or configuration migration are required. Access still depends on the connected Google account's permissions.
- New documents created from unlinked notes continue to be created in My Drive. This release adds Shared Drive browsing/import and synchronization of existing documents, not a creation destination picker.
- Update through BRAT, then fully reload Obsidian or Geode if the new Drives picker does not appear.
- Requires Obsidian 1.4.0 or later. Automated validation: 236 passing tests, clean TypeScript, and a successful build. Desktop picker checks passed in Obsidian 1.13.7 using synthetic data in light/dark themes and normal/narrow layouts. Live corporate-account verification of the final pagination changes remains a post-update smoke check.
