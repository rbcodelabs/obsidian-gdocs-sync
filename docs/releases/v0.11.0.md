## Tasks view for synced Google Tasks

A new view for your synced Google Tasks, in the right sidebar (ribbon icon) or as a tab. ([#51](https://github.com/rbcodelabs/obsidian-gdocs-sync/pull/51))

- **Filters:** Today, Upcoming, Overdue and All tabs, plus a Google task list filter.
- **Tasks:** grouped sections with nested subtasks, a checkbox to complete, and inline title and due-date editing.
- **Quick add:** new `quick-add-task` command and an in-view quick-add with a list picker. New command `open-tasks-view`.
- **Sync now** button, empty states (sync off, not connected, all done), and a *default tab* setting.
- Reads and writes task note frontmatter; the existing sync pushes changes to Google.

## Sync fix

A quick-added task note now lands in the Google list you picked. Previously it always went to the first synced list. If the chosen list is missing or not synced, it falls back to the old behavior.
